TU PROYECTO REACT PREPARADO PARA GITHUB PAGES

1) Descomprime esta carpeta y abre "miproyecto" en Visual Studio Code.
2) NO subas node_modules ni dist; no vienen dentro de este ZIP.
3) Si no tenes GitHub Desktop, instalalo desde https://desktop.github.com/
4) En GitHub Desktop: File > Add local repository > Choose... elegi la carpeta miproyecto.
   Si te dice que no es un repositorio Git, elegi "Create a Repository Here".
   Deja el archivo .gitignore existente y realiza tu primer commit.
5) Elegi Publish repository, escribi un nombre a eleccion,
   y DESMARCA "Keep this code private" para que sea publico.
6) En el navegador abre tu repositorio de GitHub: Settings > Pages.
   En "Build and deployment" > "Source", selecciona "GitHub Actions".
7) En GitHub > Actions, verifica que "Publicar tienda React en GitHub Pages" termine con marca verde.
8) GitHub > Settings > Pages mostrara el enlace del sitio "Visit site".
   Enlace tipico: https://TU-USUARIO.github.io/TU-REPOSITORIO/

Al guardar nuevos cambios, en GitHub Desktop crea un commit y hace Push origin.
GitHub Pages se actualizara automaticamente.
