TP RECUPERATORIO - PROGRAMACIÓN WEB II - UPATECO
================================================
Este proyecto incluye: React, FORMULARIO EmailJS EN LA PÁGINA PRINCIPAL, mapa de UPATECO al lado, publicación automática GitHub Pages.

MUY IMPORTANTE: Para que el formulario ENVÍE mensajes realmente hay que conectar TU cuenta de EmailJS:
1. Entrar a https://dashboard.emailjs.com/ y crear cuenta o ingresar.
2. Email Services -> Add New Service -> elegir Gmail u otro servicio -> conectar tu correo -> Create Service.
   Copiar el SERVICE ID.
3. Email Templates -> Create New Template. Configurar "To Email" con TU correo asociado al servicio.
   Usar en asunto: Mensaje de {{from_name}}
   En cuerpo:
   Nombre: {{from_name}}
   Email: {{reply_to}}
   Mensaje: {{message}}
   Configurar Reply To: {{reply_to}} si está disponible. Guardar y copiar el TEMPLATE ID.
4. Account -> General -> Public Key (en algunos paneles el dato aparece en Account).
   Copiar el PUBLIC KEY. NO copies tu PRIVATE KEY.
5. Abrir src/emailjs.config.js y reemplazar las 3 frases PEGAR_... con los IDs reales.
6. Subir el proyecto a GitHub y mandar un mensaje de prueba desde el formulario publicado para comprobar que llega al correo. SIN ESTOS 3 DATOS, EL FORMULARIO NO ENVÍA CORREOS.

SUBIR Y PUBLICAR EN GITHUB (sin terminal, usando GitHub Desktop)
1. Descomprimir este ZIP. Dentro hay una carpeta llamada miproyecto. No subir el ZIP directamente.
2. Abrir GitHub Desktop -> File -> Add local repository -> Choose -> seleccionar miproyecto.
   Si te propone Create a Repository Here, aceptar.
3. Escribir resumen "TP recuperatorio React UPATECO" y pulsar Commit to main.
4. Publish repository -> dar nombre "miproyecto", DESMARCAR "Keep this code private" -> Publish.
5. Abrir github.com/USUARIO/miproyecto -> Settings -> Pages -> Source: GitHub Actions.
6. Entrar a Actions. Si el primer despliegue no comenzó al activar Pages, reejecutar "Publicar tienda React en GitHub Pages" -> Run workflow, o realizar un nuevo commit.
7. La URL quedará como https://USUARIO.github.io/miproyecto/ (si usaste ese nombre).
8. A la plataforma educativa enviar LAS DOS URLS, del repositorio y de la página:
   https://github.com/USUARIO/miproyecto
   https://USUARIO.github.io/miproyecto/
   Cambiar USUARIO por tu verdadero usuario.
